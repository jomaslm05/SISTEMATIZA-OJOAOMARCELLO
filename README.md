# API de Profissionais de Saúde

## Descrição
API REST para consulta de profissionais de uma clínica.

## Funcionalidades
- Listagem de profissionais
- Filtro por especialidade
- Busca por nome

## Instalação
```bash
npm install
npm run dev
```

## Endpoints
- GET /profissionais
- GET /profissionais?especialidade=Cardiologia
- GET /profissionais/buscar?nome=Maria
